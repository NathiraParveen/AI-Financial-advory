# User Journey Map - Investment Advisor

## Journey: John's First Day with Investment Advisor

### Stage 1: Discovery & Onboarding (5 min)
**What John Does:**
- Visits app URL
- Sees landing page with features
- Clicks "Sign Up"

**Touchpoints:**
- Landing page
- Sign up form
- Email verification

**Emotions:** 😊 Curious, slightly skeptical
**Pain Points:**
- Worried app is too complex
- Concerned about data security

**What App Should Do:**
- ✅ Show clear value proposition
- ✅ Explain how it helps John specifically
- ✅ Make sign-up quick (< 2 min)

---

### Stage 2: Account Setup (3 min)
**What John Does:**
- Creates account with email/password
- Logs in
- Sees dashboard (empty)

**Touchpoints:**
- Register form
- Email confirmation
- First login → dashboard

**Emotions:** 😐 Neutral, waiting for content
**Pain Points:**
- Empty dashboard feels incomplete
- No guidance on next steps

**What App Should Do:**
- ✅ Show onboarding tour
- ✅ Explain what to do next
- ✅ Provide quick-start guide

---

### Stage 3: Data Upload (10 min)
**What John Does:**
1. Sees "Upload Your Data" prompt
2. Downloads CSV template
3. Fills in savings & portfolio data
4. Uploads CSV file
5. Sees data preview
6. Confirms import

**Touchpoints:**
- Dashboard → Upload button
- CSV template download
- File upload interface
- Data preview
- Confirmation dialog

**Emotions:** 😟 Concerned about format, then ✅ Satisfied
**Pain Points:**
- Worried about CSV format
- Wants to verify data before confirming
- Concerned about security

**What App Should Do:**
- ✅ Provide clear CSV template
- ✅ Show data preview before import
- ✅ Allow edit/fix before confirming
- ✅ Show error messages (line numbers)
- ✅ Reassure about data security

---

### Stage 4: Initial Dashboard View (3 min)
**What John Does:**
- Upload completes
- Dashboard refreshes
- Sees: Total savings, Portfolio value, Monthly rate, Goals count
- Scrolls down to see portfolio chart

**Touchpoints:**
- Dashboard metrics
- Portfolio pie chart
- Recent recommendations

**Emotions:** 😊 Impressed! "Oh, it actually works"
**Pain Points:**
- Too much information at once
- Unsure what to click next

**What App Should Do:**
- ✅ Show key metrics clearly
- ✅ Use visual hierarchy (most important first)
- ✅ Provide hints ("Click portfolio to see details")

---

### Stage 5: Explore Portfolio Details (5 min)
**What John Does:**
1. Clicks on Portfolio card
2. Sees holdings list (30 holdings)
3. Scrolls through table
4. Clicks on a holding (VXUS)
5. Sees: price, gain/loss, purchase date

**Touchpoints:**
- Portfolio page
- Holdings table
- Holding detail modal

**Emotions:** 😊 Engaged, learning
**Pain Points:**
- Table is long (need sorting)
- Wants to see performance metrics
- Concerned about one holding with loss

**What App Should Do:**
- ✅ Sortable table (by gain %, value, etc.)
- ✅ Color-code gains/losses
- ✅ Show performance badges
- ✅ Allow hiding/showing columns

---

### Stage 6: Discover Tax Opportunities (8 min)
**What John Does:**
1. Notices "Tax Opportunities" card on dashboard
2. Clicks it
3. Sees 3 tax-loss harvesting opportunities
4. Reads: "VXUS down 3% - Harvest $285 in losses"
5. Clicks to expand details
6. Sees recommended replacement fund (VEA)
7. Saves recommendation for later

**Touchpoints:**
- Tax Opportunities card
- Tax optimization page
- Opportunity cards
- Recommendation detail

**Emotions:** 😮 Excited! "I could save money?"
**Pain Points:**
- Worried about wash-sale rules
- Wants to understand the recommendation
- Concerned about executing trades

**What App Should Do:**
- ✅ Explain tax savings clearly ($)
- ✅ Show wash-sale explanation
- ✅ Provide recommended actions
- ✅ Show confidence level (why this fund?)
- ✅ Provide "save recommendation" for later

---

### Stage 7: Set Financial Goals (10 min)
**What John Does:**
1. Clicks "Goals" page
2. Sees button "Add New Goal"
3. Creates Goal 1:
   - Name: "Home Down Payment"
   - Target: $100,000
   - Date: Dec 2026 (1.5 years)
   - Priority: HIGH
   - Risk: MEDIUM
4. Submits
5. Sees: "You need to save $5,556/month"
6. Adjusts date to Dec 2027 (2.5 years)
7. Sees: "You need to save $3,333/month"

**Touchpoints:**
- Goals page
- Goal creation form
- Calculation results
- Adjustment controls

**Emotions:** 😟 Concerned (high savings), then ✅ Realistic
**Pain Points:**
- Initial target too aggressive
- Wants interactive adjustments
- Needs confidence that goal is achievable

**What App Should Do:**
- ✅ Show required monthly savings dynamically
- ✅ Allow adjusting date/amount interactively
- ✅ Show warning if goal unrealistic
- ✅ Suggest adjustments (timeline vs savings rate)

---

### Stage 8: Review Recommendations (5 min)
**What John Does:**
1. Goes to Recommendations page
2. Sees 5 recommendations:
   - "Rebalance portfolio" (high impact)
   - "Increase emergency fund" (medium)
   - "Tax-loss harvest VXUS" (high savings)
   - "Allocate funds to goal" (medium)
   - "Diversify sector exposure" (low)
3. Clicks on top recommendation
4. Reads explanation
5. Sees "Accept" button

**Touchpoints:**
- Recommendations page
- Recommendation cards (sorted by impact)
- Recommendation detail view
- Accept/Dismiss buttons

**Emotions:** 😊 Impressed by personalization
**Pain Points:**
- Too many recommendations
- Unsure which to prioritize

**What App Should Do:**
- ✅ Show top 3-5 recommendations first
- ✅ Prioritize by financial impact
- ✅ Show clear explanation
- ✅ Provide action buttons (Accept/Dismiss/Learn More)

---

### Stage 9: Close Session (2 min)
**What John Does:**
1. Feels confident about app
2. Bookmarks dashboard
3. Logs out

**Touchpoints:**
- Bookmark option
- Logout button
- Confirmation message

**Emotions:** 😊 Satisfied! "I'll come back"
**Pain Points:**
- Wants to be reminded about recommendations
- Needs email alerts

**What App Should Do:**
- ✅ Suggest setting up alerts
- ✅ Show next recommended action
- ✅ Confirm logout

## Emotional Arc

```
😊 Curiosity → 😟 Concern → 😐 Neutral → 😊 Engaged → 😮 Excited → 😟 Overwhelmed → ✅ Confident
Discovery    Onboarding  Empty App   Portfolio   Tax Tips   Too Much   Final State
```

**Goal:** Move users from 😟 → ✅ in one session (< 60 min)

---

## Key Insights for Development

1. **First Impression Critical** (Stages 1-2)
   - Landing page must explain value immediately
   - Sign-up must be frictionless

2. **Data Upload is Crucial** (Stage 3)
   - CSV template + preview + errors = success
   - This is where most users bail if not done well

3. **Dashboard Should Wow** (Stage 4)
   - Show computed insights (not just raw data)
   - Make users feel like their data is processed

4. **Tax Opportunity = Aha Moment** (Stage 6)
   - Dollar savings make it real
   - This feature drives retention

5. **Goals Feature = Emotional Engagement** (Stage 7)
   - Interactive calculations build confidence
   - Shows app is personalized for user

6. **Recommendations = Value Prop** (Stage 8)
   - Personalization shows the app "gets it"
   - Clear prioritization prevents overwhelm
