# BMAD Output

This directory is the designated output location for BMAD workflow artifacts.

In this project, planning and implementation artifacts were generated directly into `bmm/_bmad/bmm/` during the BMAD workflow sessions. The artifacts are organized there by phase:

- `bmm/_bmad/bmm/1-analysis/` — analysis artifacts (user stories, personas, journey maps)
- `bmm/_bmad/bmm/2-plan-workflows/` — planning documents (architecture, API contracts, sprint plans)
- `bmm/_bmad/bmm/3-solutioning/` — solutioning documents (DB schema, UI specs)
- `bmm/_bmad/bmm/4-implementation/` — live application code
